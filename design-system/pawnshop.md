# 当铺方向 · 物纪 Chronicle — 典当行设计说明

> 状态：**现行方向（v2）**，取代 DESIGN.md 的"账簿/存根"表述。DESIGN.md 保留为 v1 历史。
> 一句话：**每件物品是一张当票，整个界面是账房的柜面与库房底册。**

## 为什么是当票不是"当铺"

典当行的原生文化是"物品 × 时间 × 钱 × 凭证"：当票记录一件东西**被押入的日期、金额、期限、状态**；赎当/死当对应产品的借出归还/退役处置；"凭票取赎"意味着凭证可追溯、不可涂改——与产品原则「关键事实可追溯，修正也留痕」天然暗合。产品现有的"存根 + 票面 + 朱红勾注"骨架，本质上已是一张当票。

**红线**：典当行的核心业务是估价；本产品原则明确「不引入估值，真实现金流与预测价值分离」。当票上的票面**永远是计算出来的成本/日均成本，不是"当铺给的估价"**。我们取的是"受托保管并记账的凭证"这一层隐喻，不取"金字招牌"。

## 材料与颜色

两级间接保持：载体只写 `--c-*`，语义映射只写一遍。四组合：

增益绿全族为**苍绿**（矿石绿料，灰化偏苔：ticket `#526b4a`/`#87a780`，indigo `#3f6b57`/`#8fb5a3`）——不用弹窗森林绿/暗底薄荷绿，与朱砂、靛青同属低饱和颜料族；色调回正时不得提高饱和度。

### 当票 · 正联（宣纸白）

纸底宣纸暖白 `#e9e2d1`，当票纸 `#f8f3e6`，松烟墨 `#2a251d`，靛青墨（主操作）`#3c5871`，朱砂（印/警示/未知）`#a83226`，色阶为暖墨单色相。链接 `#2a5a8a`——比主操作更亮更艳的一档蓝，文字链接不能与按钮同墨。

### 当票 · 碑拓（暗色为拓片，不是"深色的纸"）

墨底 `#141109`，拓纸 `#2b271d`（票面比墨底亮一档：暗色无阴影，卡片层级全靠这一档），拓白 `#e9e2cf`，靛青提亮 `#6f93b4`，朱砂提亮 `#dd7a63`（对拓纸 4.99:1，随票面同步提亮）。

### 蓝印 · 正联（靛蓝印纸）

白底偏蓝 `#e7edf2`，靛青墨 `#1d3a58`，主操作饱和靛蓝 `#1e5f8d`。链接偏群青 `#2f5aa0`，与主操作拉开（两者曾同值）。

### 蓝印 · 蓝靛（暗色）

深靛蓝底 `#0d2136`，靛青 sheet `#173550`，纸白为主操作（留白是蓝靛上最有力的标记）。

## 签名元素：朱砂方印

- 形状：直角方印、双边、手绘篆意印文「物纪」（SVG 笔画竖排，不引字体），微转 -3°；印缘带四处不对称纸色残缺——印泥没盖实的位置，只咬印缘不咬笔画。
- 印泥立体：左上受光 + 右下暗角叠在深浅渐变上，内嵌浮雕——读作"压出来的"，不做模糊纹理。白文字腔按斜光刻槽读：笔画左上压深槽底、右下槽沿吃亮（上暗下亮是阴刻的阅读方向，反过来会被读成凸字）；残印缺口带一圈极细受力暗边。
- 位置：当票（资产卡）票面右侧；骑缝跨半印；登录/初始化卡头凭印；空态以淡印做水印底（opacity 0.16）；后续档案头右上。
- 动效：**盖印** —— 保存成功时印从 1.7 倍缩小落定（420ms，`cubic-bezier(0.2,0.8,0.3,1)`，单次播放）。reduced-motion 关闭。
- 印章是"凭印为信"，与可追溯留痕同义；这是全站唯一签名动效，取代 v1 的"墨迹未干"wash 作为主要反馈（fresh wash 保留为辅助）。
- 图表收笔：折线取墨色（`--foreground`）不取链接蓝——墨线是账房自己的笔（当票松烟墨、碑拓拓白、蓝印蓝黑墨，四载体自动成立）；且"淡墨入笔"——越旧的账墨越淡、越近越黑（x 方向渐变，左端 55% 起）；最新读数落一颗朱砂圆点（收笔顿点，带卡面色细描边），阶梯跳变处的方章保留——朱砂在这里不表警示，表落笔。
- 图表上的账：资金事件在曲线上落竖向灰墨虚线刻度（不写字，悬停该日的轴 tooltip 列出类型与金额；作废的账不上账页）；资产日均曲线加"全期日均"横向合脚虚线（带小字标签，比事件刻度略重、比淡墨段折线轻，避免主次倒挂；净收益为负时不画）。
- 资产版图 = 库房货架（VaultRack，纯 DOM 不用 echarts）：一格一类、宽随净投入，**架号从《千字文》「天地玄黄宇宙洪荒」起**——当铺货架的真实编号传统；架满八格后余类并入「杂格」。格内防溢出是硬约束（overflow-hidden + 截断 + 80px 格宽下限），格子太挤时货架横向滚动（与账页视图同一策略）。排行同时是版图的无障碍表格视图（货架本体 aria-hidden）。填色纪律：格子本体永远走茶褐 ramp；分类自定义色是任意十六进制，整格填色等于把调色板纪律交给手滑——降级为架号行末尾一颗色点（排行占比条的条色维持现状）。
- 长条戳与朱批（批注语言，与方印分职——方印凭信、长戳批注）：更正/作废盖 AuditStamp 长条骑缝戳（时间线条目旁，`correctionOfId`/`voidedAt` 驱动）；详情页取得日期附入册干支（`ganZhiYear`）。
- 勾注双色制（朱砂解放）：**朱砂只留给印信与判词**——印章、更正/作废戳、收笔顿点、FormError、破坏性操作（`data-slot='annotation'`）；**琥珀（藤黄）接管全部待办**——未记录、待补录、尚未服役（`data-slot='pending'`）。待办不是错误，语义也更准；待办也不用朱砂，印信的分量是靠不去用它撑起来的。图表/货架色阶为茶褐系（约 33°，陈茶汤不是苔藓），明度单调由 tokens:check 值守。
- 陈纸（`data-vintage`）：当票随年头向茶色（#8f7a4d）渐变——按 JND 可辨阈量化的五档阶梯（半年–一年半 0%、两年 3%、三年 6%、五年 9%、八年封顶 12%），不是连续函数：0→12% 的可辨空间塞不进更多档，亚阈值的"渐变"只会让卡面底色不均（`lib/vintage.ts` 为单一事实源）。亮色是茶渍微陈，碑拓是墨底转暖（方向相反：越陈越亮，物理必然），与新墨（fresh-ink）恰成一张票的首尾。档距是"并置细看可辨"的氛围级，读不出具体年头——年头去详情页看。封顶上次级文字最低 4.05:1，由 tokens:check 按"12px 补充信息、≥4.0"的氛围放宽条款钉住。
- 铅字块（TypeBlock）：分类的扫读锚点。分类名首字装进描边小方块（宋体墨色，拉丁字母大写且字号配平），不引图标库、不夹颜色、零配置。落在当票头联与账页视图分类列；票号因此压为 id 尾段四位——票号只负辨识不重查对。暗色载体下钉子描边向墨色借 28%（全局 strong 边框对细丝方块偏闷）。
- 品牌 Mark / favicon 后续重画为这枚印（手工 SVG 路径，不引字体）。

## 排版与数字

- 无外部 web font（离线要求不变）。古意靠系统字体栈：标题与眉批用宋体系（Songti SC / Noto Serif），正文无衬线、金额等宽不动；印章边字可用竖排 `writing-mode: vertical-rl`（只用于短标签，正文永不竖排）。
- 金额保持等宽现代数字；当期票惯例「大写金额防涂改」（壹贰叁…）已落详情页票面小字批注（`chineseCapitalAmount`，三位小数货币不落），不上卡片。
- 宣纸纹理：当票载体的纸底叠一层 soft-light 灰度噪点（强度收在 0.42）；蓝印载体不用——印花布上没有宣纸。
- 成色术语**不换**成"九成新/七成新"——现代用户理解速度优先；可在描述里做轻量行话。

- ❌ 水墨山水背景、祥云/回纹边框、繁体字滥用、竖排正文、铜钱/算盘 emoji、毛笔 web font、发光渐变。
- ❌ 任何「估价」文案；「市值/估值/典当行估价」词汇永不出现。
- 保留 v1 全部戒律：直角、纸不发光、颜色只表意、未知值不伪装成零、动效遵守 reduced-motion。
- 原生控件一律入材质：checkbox 直角小方盒（落墨时墨底纸勾）、radio 纸面墨点（不填底，避免甜甜圈）、date 日历指示器压暗 50%；焦点环统一走全局 `:focus-visible` 的 2px 直角 outline，组件不再自配 ring 配方。
