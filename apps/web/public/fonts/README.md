# Fusion Pixel Font

Chronicle self-hosts the Simplified Chinese and Latin webfont subsets from
[Fusion Pixel Font](https://github.com/TakWolf/fusion-pixel-font).

- Release: `2026.07.20`
- Files: 10px proportional OTF WOFF2 builds for Latin and `zh_hans`
- License: SIL Open Font License 1.1; see `FUSION-PIXEL-OFL.txt`
- Usage: short headings, labels, buttons, navigation, dates, and numeric readouts

Long-form Chinese body copy intentionally remains on the platform system-sans stack for readability.
